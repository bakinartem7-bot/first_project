# sorting-project
Командный учебный проект по Java: сортировка объектов

## Что сделано


- **Модель**: `model.Car` (поля `power`, `model`, `year`) с паттерном Builder
  и методами `equals`/`hashCode`.
- **Коллекция**: `collection.CarArrayList` — собственная коллекция на динамическом
  массиве (`implements Iterable<Car>`); `add`, `get`, `set`, `remove`, `size`,
  итератор и рост ёмкости реализованы вручную.
- **Валидация**: `validation.CarValidator` и `validation.ValidationResult` —
  единый источник правил, вызывается из `Car.Builder.build()`.
  - мощность — целое от 1 до 2000, отдельно запрещены отрицательные значения;
  - модель — не пустая и не null;
  - год — от 1886 до 2026;
  - при нарушении правил `build()` бросает `IllegalArgumentException`.

- **Консоль**: `console.ConsoleInput` (чтение строки и числа с проверкой диапазона),
  `console.Menu` / `console.MenuItem`, лимит неудачных попыток
  (`AttemptsExceededException`) и обработка конца ввода (`EndOfInputException`).
- **Ручное заполнение**: `fill.ManualFiller` — ввод по одному полю
  (Мощность / Модель / Год) с подсказками и повторным вводом при ошибке;
  результат возвращается как `CarArrayList`.
- **Сохранение результата**: `io.CarLineFormat` (формат `мощность;модель;год`)
  и `io.ResultSaver` (принимает любую `Iterable<Car>`, атомарная запись
  в файл `results/cars.txt`).
- **Статистика**: `stats.SortingStatistics`.
- **Утилиты**: `common.Limits` (лимиты), `common.TextSanitizer` (очистка текста).
- **Точка входа**: `Main` — цикл главного меню:
  1. заполнить коллекцию вручную, 2. сохранить коллекцию в файл, 3. выход;
  ошибки обрабатываются с возвратом в меню.

## Тесты

JUnit 5 (`junit-bom 5.11.4`). Покрыто 15 тестовых классов, 106 тестов:
валидация, модель, коллекция (`CarArrayList`), консольный ввод, меню,
ручное заполнение, формат строки, сохранение, статистика и сценарий `Main`.

Найденные и исправленные баги:

- счётчик неудачных попыток сбрасывался при успешном разборе (`markSuccess`),
  из-за чего лимит попыток не срабатывал;
- добавлена явная проверка отрицательной мощности с понятным сообщением.

## Запуск

Проект собирается на Java 21 (toolchain), Gradle 9.3.0.

```
./gradlew run      # запуск приложения
./gradlew test     # запуск тестов
./gradlew build    # полная сборка
```
